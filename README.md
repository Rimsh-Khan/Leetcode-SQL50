## About This Repository

This repository contains my solutions to the LeetCode SQL 50 Study Plan, where I practice SQL by solving real-world, problem-oriented database questions.

The objective is to strengthen my SQL fundamentals, improve query-writing skills, and develop logical problem-solving abilities for Data Analyst roles.

Develop analytical thinking through SQL queries.

Improve query-writing efficiency and accuracy.
